# The Gate Was Open

A short poem about permission, told through a river and its banks: the water asks to run, the banks never answer in words — they widen. Permission, the poem argues, is not a word granted from above but ground stepping back so something can become what it is. The entry is a small deterministic Node program (`main.ts`) that writes the poem to `/output/entry.txt`.
